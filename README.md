# Open Lode

A September 2026 briefing on Australia’s open critical minerals projects, read by Leo — an English gentleman.

Press play on **The identity file** for the tantalum special, or **The border** for Myanmar. Earlier briefings run from Australia through India, plus the rhenium kilogram. Projects named in the recording are marked **In the briefing**.

Figures are compiled from public reports (the major-projects list, Austrade’s prospectus, and company statements). They are a reading list, not advice.

```bash
npm install
npm run dev
```
